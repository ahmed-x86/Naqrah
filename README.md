
# 🪶 نقرة (Naqrah)

**نقرة** هو تطبيق رسومي (GUI) مفتوح المصدر مكتوب بلغة **C++** باستخدام إطار عمل **Qt6**. يهدف التطبيق إلى تسهيل عملية إضافة التشكيل (الحركات) إلى النصوص العربية يدوياً بدقة عالية، عبر واجهة مستخدم عصرية توفر تجربة كتابة وتحرير خالية من التشتت.

## ✨ المميزات الجديدة في هذا الإصدار

* **واجهة مستخدم حديثة (Modern Dark Mode):** تصميم أنيق وبسيط يعتمد على نظام ألوان (Zinc) المريح للعين، مستوحى من أحدث أنظمة تصميم الويب، ليوفر بيئة عمل احترافية.
* **دعم مثالي للغة العربية (BiDi):** معالجة برمجية متقدمة لاتجاه النصوص (RTL) تضمن عدم تداخل الأقواس مع علامات التشكيل (الفتحة، الضمة، إلخ) أثناء التحرير.
* **تجربة استخدام متجاوبة (Responsive):** واجهة تتكيف تلقائياً مع حجم النافذة (Responsive Layout) مع أزرار مهيأة لدعم اللمس (Touch-optimized) لمختلف الشاشات.
* **خفيف وسريع:** مبني بالكامل على لغة C++ ومكتبات Qt الأساسية لضمان أداء فائق واستهلاك منخفض لموارد النظام دون أي تأخير في معالجة النصوص.
* **تشكيل دقيق:** إضافة الحركات حرفاً بحرف (فتحة، ضمة، كسرة، سكون، شدة، تنوين) مع إمكانية النسخ المباشر بضغطة زر.

## 🛠️ التقنيات المستخدمة

* **C++17**
* **Qt6** (Core, Gui, Widgets)
* **CMake** (نظام البناء)

## 🚀 كيفية التثبيت والبناء 

التطبيق يدعم أنظمة لينكس، ويندوز، وأندرويد. تأكد من تثبيت أدوات البناء الأساسية ومكتبات Qt6 في نظامك.

### البناء على أنظمة لينكس:
```bash
# استنساخ المستودع
git clone https://github.com/ahmed-x86/Naqrah.git
cd Naqrah

# استخدام سكريبت البناء الجاهز
chmod +x build.sh
./build.sh

# أو البناء يدوياً باستخدام CMake:
mkdir build && cd build
cmake ..
cmake --build .
./Naqrah

```

*(تتوفر أيضاً سكريبتات `build-win.sh` للبناء المتقاطع الخاص بنظام ويندوز).*
