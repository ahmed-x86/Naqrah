# 🪶 نقرة (Naqrah)

**نقرة** هو تطبيق رسومي (GUI) مفتوح المصدر مكتوب بلغة **C++** باستخدام إطار عمل **Qt6**. يهدف التطبيق إلى تسهيل عملية إضافة التشكيل (الحركات) إلى النصوص العربية يدوياً بدقة وسهولة، مع توفير واجهة مستخدم عصرية وتفاعلية.

## ✨ المميزات

* **واجهة مستخدم عصرية:** تصميم مرن وجميل يدعم التأثيرات الحركية (Ripple Effects) والإضاءة المحيطية (Glow).
* **تشكيل دقيق:** يتيح لك إضافة الحركات (الفتحة، الضمة، الكسرة، السكون، الشدة، والتنوين) حرفاً بحرف لتجنب الأخطاء.
* **دعم الثيمات (Themes):** يأتي التطبيق مع عدة سمات ألوان مدمجة تناسب ذوقك (مثل سمة *Catppuccin Mocha* الافتراضية، *Latte*، *Nord*، *Gruvbox*، و *Shamela Classic*)، مع إمكانية إنشاء سمة مخصصة بالكامل.
* **تصميم متجاوب:** يتكيف التطبيق مع مختلف أحجام الشاشات ليعمل بكفاءة سواء في الوضع الرأسي أو الأفقي.
* **خفيف وسريع:** مبني باستخدام لغة C++ ومكتبات Qt الأساسية لضمان أداء عالٍ واستهلاك منخفض لموارد النظام.

## 🛠️ التقنيات المستخدمة

* **C++17**
* **Qt6** (Core, Gui, Widgets)
* **CMake** (نظام البناء)

## 🚀 كيفية التثبيت والبناء (لأنظمة لينكس)

تأكد أولاً من تثبيت أدوات البناء الأساسية ومكتبات Qt6 في نظامك.

### 1. استنساخ المستودع:
```bash
git clone https://github.com/ahmed-x86/Naqrah.git
cd Naqrah
```

### 2. البناء باستخدام CMake:
```bash
mkdir build && cd build
cmake ..
cmake --build .
```

### 3. التشغيل:
```bash
./Naqrah
```
