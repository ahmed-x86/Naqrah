
# 🪶 نقرة (Naqrah)

**نقرة** هو تطبيق رسومي (GUI) مفتوح المصدر تمت إعادة كتابته بالكامل بلغة **Rust** باستخدام إطار عمل **Tauri v2**. يهدف التطبيق إلى تسهيل عملية إضافة التشكيل (الحركات) إلى النصوص العربية يدوياً بدقة عالية، عبر واجهة مستخدم عصرية توفر تجربة كتابة وتحرير خالية من التشتت.

## ✨ المميزات 

* **واجهة مستخدم حديثة (Modern Dark Mode):** تصميم أنيق وبسيط يعتمد على نظام ألوان (Zinc) المريح للعين، مستوحى من أحدث أنظمة تصميم الويب، ليوفر بيئة عمل احترافية[cite: 7]. تم بناؤه باستخدام Pure CSS بدون أي مكتبات خارجية.
* **أداء خارق وحجم مجهري (KISS Principle):** تم التخلص من الاعتماديات الثقيلة ومجلدات الـ `node_modules`. بفضل لغة Rust وأداة الضغط UPX، يبلغ حجم الملف التنفيذي أقل من 1 ميجابايت مع استهلاك شبه معدوم لموارد النظام.
* **دعم مثالي للغة العربية (BiDi):** معالجة برمجية متقدمة لاتجاه النصوص (RTL) تضمن عدم تداخل الأقواس مع علامات التشكيل (الفتحة، الضمة، إلخ) أثناء التحرير.
* **تجربة استخدام متجاوبة (Responsive):** واجهة تتكيف تلقائياً مع حجم النافذة (Responsive Layout)
* **تشكيل دقيق:** إضافة الحركات حرفاً بحرف (فتحة، ضمة، كسرة، سكون، شدة، تنوين) مع إمكانية النسخ المباشر بضغطة زر.

## 🛠️ التقنيات المستخدمة

* **الخلفية (Backend):** Rust & Tauri v2
* **الواجهة الأمامية (Frontend):** Vanilla HTML, Pure CSS, Vanilla JavaScript (Zero Dependencies)
* **نظام البناء والضغط:** Cargo & UPX

## 🚀 كيفية التثبيت والبناء 

التطبيق يدعم أنظمة لينكس وويندوز. تأكد من تثبيت بيئة لغة Rust (`cargo`) في نظامك.

### البناء خطوة بخطوة:
```bash
# استنساخ المستودع
git clone https://github.com/ahmed-x86/Naqrah.git
cd Naqrah

# لتشغيل التطبيق للتجربة (Development Mode)
cargo run

# لبناء النسخة النهائية (Release)
cargo build --release

# لضغط الملف التنفيذي لأقصى درجة (يتطلب تثبيت حزمة upx)
upx --best --lzma target/release/naqrah

```

*ستجد الملف التنفيذي النهائي المضغوط داخل مسار `target/release/naqrah`.*
